# Как это работает?
Расписание [отсюда](https://cloud.mail.ru/public/xqay/nJth4nGAS) скачивается на основной сервер, там оно разделяется с помощью базового NLP и LLM на мероприятия. После всё это собирается в один большой список.

Из-за работы LLM могут случаться ошибки. Чем точнее структурированней составлено основное расписание, тем лучше оно будет отражено здесь.
