# Как это работает?

Расписание [отсюда](https://cloud.mail.ru/public/xqay/nJth4nGAS) скачивается на основной сервер. Там оно разделяется с помощью базового NLP и LLM на мероприятия. После всё это собирается в один большой список.

В одной ячейке таблицы часто лежит сразу несколько занятий — разные даты, преподаватели, иногда предметы. Нейросеть разбирает такую ячейку на отдельные мероприятия. Дальше сервер добавляет день недели и время, проверяет даты и раскладывает всё по группам и преподавателям.

На сайте можно листать календарь (неделя / месяц / день), фильтровать по группам и преподавателям и подписаться на своё расписание в Google Calendar — подписка обновляется сама, если расписание поменялось.

~~~~После работы LLM могут случаться ошибки. Чем структурированней составлено основное расписание, тем лучше оно будет отражено здесь.
